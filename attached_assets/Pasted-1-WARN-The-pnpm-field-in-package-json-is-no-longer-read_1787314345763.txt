Remove deprecated configuration: Delete the pnpm.onlyBuiltDependencies field from package.json as it's no longer supported in pnpm v11
Update pnpm configuration: Add .pnpmrc file with only-built-dependencies=["esbuild"] to replace the deprecated setting
